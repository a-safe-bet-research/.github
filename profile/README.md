# A Safe Bet

An adaptive responsible gambling research programme at Erasmus University Rotterdam. A Safe Bet develops and evaluates a framework for tailoring responsible gambling tools (deposit, loss, bet and playtime limits) to individual risk, deployed on live commercial platforms in the United Kingdom and the Netherlands.

Funded by the International Center for Responsible Gaming in collaboration with Playtech PLC and Holland Casino N.V.

## How the research record is organised

| Where | What |
|---|---|
| [OSF Registries](https://osf.io/registries) | Preregistrations, unchanged |
| Preprint server | Manuscripts before publication; linked from each repository |
| This organisation | Working code, documentation and shareable materials, version-controlled |
| [Zenodo](https://zenodo.org) | The fixed, DOI-stamped version of each repository at submission and publication |
| Data repository or access statement | Research data, held separately; each repository states what is available and how |

Historical materials remain on the original OSF projects: [A Safe Bet](https://osf.io/cdpw4/) (DOI 10.17605/OSF.IO/CDPW4).

## Repositories

| Repository | Study | Status |
|---|---|---|
| `common` | Shared programme materials: data dictionary, framework design, ethics and governance, conventions | active |
| `framework` | Evidence review, responsible gambling tool taxonomy and intervention framework | under revision |
| `poc` | Proof-of-concept evaluation on SunVegas UK | in preparation |
| `template-study` | Starter structure for new study repositories | template |

Further study repositories are added as studies begin.
